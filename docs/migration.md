## Data conventions

Prepared behavior uses global impression_id with source and orig_impression_id retaining raw identity. Global ordering follows the original MLP stable chronological sort. Hybrid imp_id is now impression_id and its consumers use the same prepared identity.

news_id2idx is the one-based article index for padded model arrays. CBF's original zero-based nidx is cbf_row_idx, retaining its separate meaning. Descriptive full-catalog category IDs and training-fitted MLP category vocabularies remain distinct. NRMS news2idx/idx2news references use news_id2idx/news_idx2id without changing article ordering.

## Behavior preservation

Existing advanced architectures, formulas, losses, sampling, tuning and information windows are retained. MLP and NRMS metric variants remain distinct where their source semantics differ. Reporting history cohorts use the requested 0, 1-4 and >=5 boundaries. Feature-group ablations remain model-selection experiments; data features, normalization and prepared arrays are generated by feature engineering.

Three basic project baselines were added: training click-count popularity, binary-user-item cosine UBCF with fixed K=200, and unweighted content-profile cosine CBF. They use the existing hybrid evaluator. Smoothed/tuned CTR remains an advanced scorer. MLP is not a project baseline.

The original embedding demonstration is covered by the full CBF representation producer. Hard-coded descriptive tables and fixed pie-chart percentages are historical report material, not freshly measured EDA. Current EDA exports computed summaries. Hard-coded NRMS absent-seed scores were replaced by actual measured seed workflows; missing experiment artifacts are not fabricated.

The original first-day popularity fallback and advanced lagged/online information policies remain explicit. Cold-article windows and candidate selection retain source behavior. The original NRMS evaluator does not have an article-cold cohort; none was invented.

## Artifacts

Download and Google Drive operations are retained through configuration. Generated outputs are separated by experiment and are ignored by Git. Historical reports remain separate from new runs. Check model state shapes/names and input contracts before reusing old checkpoints. Regenerate embedding caches when dataset content or feature configuration changes.

Source-file content hashes are recorded with preprocessing metadata. Feature bundles have a final manifest of exported content hashes and preparation identity. Model validation does not require the original raw-file location. Output roots reject a different feature identity.

## Unified feature revision

The latest user instruction authorizes corrections to conflicting feature implementations. A single sentence-level content representation and normalized mean TransE representation are now produced for consumers. CBF reads those same arrays rather than generating a second embedding. Missing entity vectors and empty history profiles are zero; category match is binary, with zero for an empty history. Category/subcategory embedding widths are 32/32. Existing MLP lagged smoothed CTR is retained as the canonical historical popularity feature. Neural title sequences are separate token inputs, not competing semantic article embeddings.

EDA computes descriptive features from preprocessed tables, uses the earliest impression snapshot consistently for user-level history statistics, retains zero inactivity gaps for the full numeric summary, and computes numeric/categorical/text/entity tables, category-match/history pies and split comparisons. Descriptive full-period CTR is kept separate from lagged model inputs. These revisions supersede the earlier preservation claims for the changed features; historical report numbers are not claimed to have been reproduced without real data.

## Portable feature bundles and Colab setup

Pipeline notebooks include an optional Colab setup cell. Source signatures use content hashes; the final feature manifest is published after all exports. MLP/NRMS validation works after relocation without raw files. Missing/changed exported contents and output roots bound to another feature identity are rejected. MLP reusable-run specifications include the feature identity; attention settings also record both categorical widths. Existing bundles without a manifest must be regenerated. These changes do not change model formulas or split membership.
